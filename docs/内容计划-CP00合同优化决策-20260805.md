# 内容计划 CP-00 合同优化决策

> 日期：2026-08-05  
> 关联：`ADR-CP-0001-related-keywords-30-seed-contract.md`

两份 V1.0 参考文档保持原样，便于追溯原始需求。本文件只记录用户接受的必要偏差，不改变其他规则。

## 唯一偏差

原 CP-00/CP-03 写为“一次 HTTP 请求提交 30 个 Related Keywords task”。DataForSEO 公开 Live 合同规定每次调用只能包含一个 task，因此改为：

- 一个内容计划服务端逻辑批次仍处理 30 个种子；
- worker 为 30 个种子分别发出单 task Live 请求，并受配置化并发上限控制；
- 前端仍只发起一次内容计划批次，不接触逐词供应商调用；
- 每项结果、错误和费用独立落账，批次层汇总；
- 原单次批量费用公式作废，真实费用以供应商逐项响应为准。

## 未改变的规则

- 自动内容计划目标仍固定为 30 个计划项。
- `unknown` 与 `uncovered` 覆盖状态仍严格区分。
- 部分失败不得清除已成功的付费结果。
- 可能计费的调用仍先进入持久化请求账本，Temporal 不自动重发。
- 本决策不增加关键词来源，也不授权 D3-D7 的业务实现。
