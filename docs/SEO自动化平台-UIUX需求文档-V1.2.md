# SEO 自动化平台 UI/UX 需求文档 V1.2

| 项目     | 内容                                             |
| -------- | ------------------------------------------------ |
| 文档版本 | V1.2                                             |
| 文档日期 | 2026-07-21                                       |
| 当前阶段 | 纯前端静态可交互原型                             |
| 默认项目 | ElephTV / elephtv.com                            |
| UI 技术  | React、TypeScript、Vite、Shadcn UI、Tailwind CSS |

## 1. 本轮目标

在现有 SEO 前端的视觉体系内融合完整的外链增长工作流，用于验证信息架构、页面统一性、主要状态和交互反馈。

本轮不连接真实后端，不调用 Supabase/Postgres、Temporal、DataForSEO、Gmail API，不执行真实发送、任务队列、联系人验证或链接检查。

## 2. 信息架构

| 一级模块     | 二级页面                                     | 融合要求                                                           |
| ------------ | -------------------------------------------- | ------------------------------------------------------------------ |
| 项目总览     | 外链旅程工作总览                             | 用流程旅程替代普通 Dashboard，展示 KPI、八阶段状态、今日任务和活动 |
| 外链         | 网站项目、推荐池、外链机会、邮件中心         | 网站项目不占用独立一级导航；项目管理与外链生命周期在同一工作区完成 |
| 效果         | 搜索表现、内容表现、链接监控、指标与报告     | 链接监控显示 active、changed、lost；报告提供客户安全预览           |
| 项目设置     | 项目资料、数据连接、外联规则与治理、通知设置 | 展示 Gmail-first、安全限额、渐进验证、抑制和通知策略               |
| 顶部任务中心 | 生命周期下一步                               | 汇总补联系人、确认发送、修复链接和生成报告                         |

## 3. 外链生命周期

```text
推荐池
-> 加入外链机会
-> 待补联系人
-> 可写信
-> 邮件草稿
-> 人工确认发送
-> 已发送 / 待回复
-> 已回复 / 洽谈
-> 已获得链接
-> active / changed / lost
-> 客户报告
```

一个网站在同一项目中只有一个主阶段。页面之间通过阶段筛选展示同一机会，而不是复制独立状态。

## 4. 页面要求

### 4.1 项目总览

- 顶部 KPI：有效推荐、活跃机会、邮件回复率、健康外链。
- 主体为八阶段外链旅程图，每一阶段可点击进入对应页面。
- 右侧展示今日下一步，任务直接跳转到需要处理的上下文。
- 下方展示项目推进状态和最近活动。

### 4.2 推荐池

- 展示推荐网站、匹配度、权威度、月流量、主题相关性和可联络性。
- 支持搜索、刷新推荐和加入机会。
- 加入后从推荐列表移除，并在外链机会中生成 `待补联系人` 状态。

### 4.3 外链机会

- 展示网站、当前阶段、联系人、权威度、下一步和更新时间。
- 支持按生命周期状态筛选。
- 支持补联系人、生成开发信草稿和打开详情抽屉。
- 详情必须显示当前唯一生命周期状态。

### 4.4 邮件中心

- 内部分类：可写信、邮件草稿、待回复、智能邮箱。
- 草稿必须可编辑，并明确说明不会真实发送。
- “确认发送”只更新本地 mock 状态，并给出清晰成功反馈。
- 智能邮箱展示模拟回复和报价状态。

### 4.5 链接监控

- KPI 显示 active、changed、lost 和下次检查时间。
- 支持模拟检查全部链接。
- changed 和 lost 状态可以创建修复任务反馈。

### 4.6 指标与报告

- 展示新增机会、收到回复、健康链接等简单 KPI。
- 报告预览不得包含内部成本、供应商报价、API 原始响应、token、prompt 或调试字段。
- 支持模拟生成和导出预览。

### 4.7 外链内的网站项目

- “网站项目”是外链模块首个页签，支持归档和恢复，不在侧边栏创建独立模块。
- 新建项目统一从左侧项目切换器的“新建项目”进入，复用网站项目页的两步式抽屉；网站项目页内不再放置重复的新建按钮。
- 默认项目资料为 `ElephTV`、`https://elephtv.com`、美国英语市场。
- 网站项目页定位为“外链项目控制台”，不使用大卡片陈列项目，也不重复侧边栏已有的项目切换器。
- 当前项目摘要必须展示外链准备度、当前阶段、推荐数量、活跃机会、邮件状态、链接健康和待办任务。
- 外链准备度必须能够展开为可执行清单，至少覆盖域名资料、目标市场、核心关键词、品牌介绍、发件邮箱和外联规则。
- 项目列表使用高密度表格，展示当前项目、运行状态、准备度、外链阶段、机会、邮件、链接健康、更新时间和状态驱动的下一步操作。
- 状态驱动操作包括完成设置、查看推荐池、继续处理机会、处理链接异常、恢复暂停项目和恢复归档项目。
- 网站项目页不展示 `BL-AI-*` 编号、Gateway 合同、运行底座或其他内部工程验收信息。
- “刷新推荐”只属于推荐池上下文，不在网站项目页头部展示。
- 新建项目使用两步式抽屉，先填写域名、名称和市场，再选择关键词、外链目标和人工确认策略；创建动作不得隐含推荐生成或邮件发送。
- 项目控制台必须提供首屏 Skeleton，以及无项目、筛选无结果和搜索无结果三类可恢复空状态；无项目状态引导用户使用左侧项目切换器。
- 暂停和归档项目必须二次确认，并明确说明哪些推进动作停止、哪些项目数据继续保留。
- 当前项目摘要提供项目级 AI 建议，根据准备度、暂停状态、待回复邮件、异常链接和机会数量给出单一下一步操作；原型阶段使用静态规则和假数据。
- 链接健康与异常处理统一跳转到“效果 > 链接监控”，不在外链模块重复设置“链接监控”页签。
- 指标和客户安全报告统一放在“效果 > 指标与报告”，不在外链模块重复设置报告页签。
- 外联安全限额、人工确认、审计保留和客户数据边界统一放在“项目设置 > 外联规则与治理”，不在外链模块重复设置治理页签。
- 外联规则默认启用人工确认、60 秒间隔、24 小时滚动上限 50 封、禁止自动追发。
- 展示渐进式联系人验证和退订、拒绝、退信、重复域名、高风险网站抑制规则。

## 5. 视觉与字体

- 延续当前浅色、紫色主色、卡片化、细边框和 Shadcn UI 组件风格。
- 桌面端和移动端根字号均使用 `16px`，保持原前端的信息密度。
- 所有布局尺寸以 `rem` 为主，让侧栏、间距、按钮和弹窗随字号同步适配。
- 核心操作文字、表格正文和状态文字优先使用 `text-sm` 或更大层级。
- 表格在窄屏下允许横向滚动，卡片网格按断点降列。

## 7. 验收标准

- 页面可以直接打开，默认进入 ElephTV 项目总览。
- 侧栏、Tab、旅程阶段和顶部任务可以完成页面跳转。
- 推荐网站可加入机会，机会可补联系人和生成草稿。
- 邮件草稿可打开、编辑并模拟确认发送。
- 链接可以模拟检查并为异常生成修复任务反馈。
- 外链模块只保留网站项目、推荐池、外链机会和邮件中心四个页签。
- 外链模块内的网站项目页签可模拟切换、筛选、搜索、查看准备度、暂停恢复、归档和恢复。
- 左侧项目切换器的“新建项目”可打开两步式抽屉，并可前进、返回、校验域名、选择外链目标和切换人工确认策略。
- 搜索或筛选无结果时展示对应空状态，并可一键清除条件；无项目时引导使用左侧项目切换器新建。
- 暂停和归档操作弹出确认窗口；项目级 AI 建议可跳转到准备度、推荐池、机会、邮件或链接监控。
- 链接监控归属“效果”，指标与报告归属“效果”，治理能力归属“项目设置 > 外联规则与治理”。
- 旧外链链接监控、报告和设置地址分别重定向到上述融合页面。
- 指标与报告可模拟生成。
- 根字号保持 `16px`，项目表格允许容器内横向滚动，页面本身不出现横向溢出。
- `npm run typecheck`、`npm run lint`、`npm run build` 通过。
