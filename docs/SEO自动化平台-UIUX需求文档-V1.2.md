## 0. 原型与生产验收边界

1. 原型轨道只验证视觉、信息架构和交互。fixtures/Mock 必须位于测试、
   Storybook 或明确的开发专用入口。
2. 生产轨道只接受 Gateway/Core 真实合同、服务端持久化状态和分层的
   Runtime、DataForSEO、Browser、AI、Gmail 与 UAT 证据。
3. 生产路由不得在真实 API 失败时回退到 Mock、假成功或本地成功状态。
4. 构建、HTTP `200`、截图、Mock 操作和生成 Client 不得单独满足生产
   验收。
5. 页面刷新、挂载、轮询和项目切换只能读取状态，不能触发新的付费
   Provider、AI 或发送操作。

## 1. 本轮目标

本文原始目标是在现有 SEO 前端视觉体系内验证外链增长工作流的信息
架构、页面统一性、主要状态和交互反馈。

“不连接真实后端、不调用 Provider、不执行真实发送或链接检查”只适用
于隔离的历史原型轨道，不适用于生产实现或生产验收。

## 2. 信息架构

| 一级模块 | 二级页面 | 融合要求 |
|---|---|---|
| 项目中心 | 项目列表、新建、切换、归档、恢复 | 生产唯一项目管理入口为 `/projects`；侧栏切换器使用同一项目上下文 |
| 项目总览 | 外链旅程工作总览 | 用流程旅程替代普通 Dashboard，展示 KPI、八阶段状态、今日任务和活动 |
| 外链 | 推荐池、外链机会、邮件中心 | 不再提供第二套“网站项目”页；外链读取当前 Platform Project 和版本化外联资料 |
| 效果 | 搜索表现、内容表现、链接监控、客户报告 | 链接监控显示 active、changed、lost；报告提供客户安全预览 |
| 项目设置 | 项目资料、数据连接、外联规则、通知设置 | 展示 Gmail-first、安全限额、渐进验证、抑制和通知策略 |
| 顶部任务中心 | 生命周期下一步 | 汇总补联系人、确认发送、修复链接和生成报告 |

## 3. 外链生命周期

```text
推荐池
-> 加入外链机会
-> 待补联系人
-> 可写信
-> 邮件草稿
-> 人工确认发送
-> 已发送 / 待回复
-> 已回复 / 洽谈
-> 已获得链接
-> active / changed / lost
-> 客户报告
```

一个网站在同一项目中只有一份权威业务记录，但推荐资格、生成操作、
合作路径、联系人、草稿、发送、回复、谈判、Placement、链接监控和
报告是独立事实。界面可派生主要阶段和下一步操作，但不得用一个状态
覆盖这些事实。

## 4. 页面要求

### 4.1 项目总览

- 顶部 KPI：有效推荐、活跃机会、邮件回复率、健康外链。
- 主体为八阶段外链旅程图，每一阶段可点击进入对应页面。
- 右侧展示今日下一步，任务直接跳转到需要处理的上下文。
- 下方展示项目推进状态和最近活动。

### 4.2 推荐池

- 展示推荐网站、匹配度、权威度、月流量、主题相关性和可联络性。
- 支持搜索、刷新推荐和加入机会。
- 加入后从推荐列表移除，并在外链机会中生成 `待补联系人` 状态。

### 4.3 外链机会

- 展示网站、当前阶段、联系人、权威度、下一步和更新时间。
- 支持按生命周期状态筛选。
- 支持补联系人、生成开发信草稿和打开详情抽屉。
- 详情必须显示当前唯一生命周期状态。

### 4.4 邮件中心

- 内部分类：可写信、邮件草稿、待回复、智能邮箱。
- 草稿必须可编辑，并明确说明不会真实发送。
- “确认发送”只更新本地 mock 状态，并给出清晰成功反馈。
- 智能邮箱展示模拟回复和报价状态。

### 4.5 链接监控

- KPI 显示 active、changed、lost 和下次检查时间。
- 支持模拟检查全部链接。
- changed 和 lost 状态可以创建修复任务反馈。

### 4.6 客户报告

- 展示新增机会、收到回复、健康链接等简单 KPI。
- 报告预览不得包含内部成本、供应商报价、API 原始响应、token、prompt 或调试字段。
- 支持模拟生成和导出预览。

### 4.7 项目中心与外链设置

- `/projects` 是唯一项目管理入口，负责新建、进入、归档和恢复。
- App Shell 项目切换器必须与 `/projects` 使用同一个服务端项目列表和
  当前项目 ID。
- 外链模块不得再增加“网站项目”页签。产品、关键词、目标 URL、受众、
  合作目标和市场范围在项目设置中作为版本化外联资料编辑。
- 新建项目继续使用全局创建流程和网站业务识别，不创建第二个外链项目。
- 外联规则默认启用人工确认、60 秒间隔、24 小时滚动上限 50 封、禁止自动追发。
- 展示渐进式联系人验证和退订、拒绝、退信、重复域名、高风险网站抑制规则。

## 5. 视觉与字体

- 延续当前浅色、紫色主色、卡片化、细边框和 Shadcn UI 组件风格。
- 桌面端和移动端根字号均使用 `16px`，保持原前端的信息密度。
- 所有布局尺寸以 `rem` 为主，让侧栏、间距、按钮和弹窗随字号同步适配。
- 核心操作文字、表格正文和状态文字优先使用 `text-sm` 或更大层级。
- 表格在窄屏下允许横向滚动，卡片网格按断点降列。

## 7. 验收标准

- 页面可以直接打开，默认进入 ElephTV 项目总览。
- 侧栏、Tab、旅程阶段和顶部任务可以完成页面跳转。
- 推荐网站可加入机会，机会可补联系人和生成草稿。
- 邮件草稿可打开、编辑并模拟确认发送。
- 链接可以模拟检查并为异常生成修复任务反馈。
- 项目中心可模拟新建、切换、归档和恢复；外链模块不得出现第二套网站项目页签。
- 客户报告可模拟生成。
- 字号放大后不出现主要按钮截断、卡片重叠或桌面布局溢出。
- `npm run typecheck`、`npm run lint`、`npm run build` 通过。
